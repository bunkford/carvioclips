# Carvio clips

Clip packs and single clips for [Carvio](https://carviocnc.com), with the scripts that made them.

A `.carvioclips` file is a clip pack. Open it in Carvio with **File > Import...** (or drop it on
the window) and all its clips go into your clipart library, in a new folder named after the pack.
A `.carvioclip` file is a single clip.
