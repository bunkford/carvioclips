# Trees

`trees.carvioclips`: 53 trees for outdoor scenes. Oaks, maples, birches, willows, elms, poplars,
fruit trees, cherry blossom, beech, olive, acacias, baobabs, spruces, firs, pines, cedars,
cypresses, junipers, larch, palms and a Joshua tree, many in several shapes and sizes, with bare
winter and snowy versions. Every tree is a 3D relief clip with leaves, needles and bark you can
see, rounded over at the outline so thin twigs and leaf tips stay carvable. Place, size and carve
them with 3D roughing and finishing.

## Source

`source/` holds the generator, written in Nim against Carvio's own code. Each tree is grown in 3D
(trunk, limbs, twigs, leaf clumps, needles, fronds), then projected into a side-view relief
with its depth squeezed into a few millimetres. `source/README.md` explains how to build the
pack and the pictures from the Carvio repository; `catalog.nim` has every tree's name,
description, tags and the pack order.
